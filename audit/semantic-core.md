### Правила распределения запросов (антиканнибализация)
- Один интент = одна посадочная. Розничный «купить+наличие» ≠ кастомный «на заказ+тираж».
- title по шаблону: «{Запрос} — {выгода} | Профлаг» (≤70 знаков), H1 без стоп-слов-каннибалов.
- Внутренняя перелинковка: категория → подкатегории → карточки → кейсы → статьи (и обратно).
