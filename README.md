## Топ-5 критических находок

1. print.proflag.ru (пункт меню «Печать на ткани») — сломан, отдаёт ошибку хостинга
2. robots.txt закрывает `/images/` — картинки не индексируются, нет трафика из поиска по картинкам
3. Индексация в Яндексе падает (290 стр., −64/мес) — шаблонные дубли и тонкие страницы
4. Нет реквизитов юрлица на сайте; владелец домена — Private Person (доверие/E-E-A-T)
5. Нет товарных карточек с ценой и наличием — по «купить»-запросам выдачу забирают магазины (291–900 ₽) и megaflag.ru (ИКС 360, 1385 стр. в индексе)
